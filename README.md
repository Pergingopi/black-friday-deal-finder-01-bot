DealHunt is a static Black Friday and Cyber Monday deal finder with 18 real deals from Walmart, Best Buy, Target and Ring. Every price was read from the store's own product page on Nov 27, 2026, and each deal shows its sale price, usual price, discount, store link, check time, source, and an honest verdict on whether it is really a deal (record low, strong, solid or modest). Search by product, filter by category, store and minimum discount, sort by discount, saving or price, and open any deal's own page for the full evidence.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
